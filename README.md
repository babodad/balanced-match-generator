
# Magic Tournament Tools 🎴

Ein vielseitiges Streamlit-Tool zur Turnierplanung für Magic: The Gathering und andere Kartenspiele.

## Enthaltene Tools

### 🔹 Balanced Match Generator (klassisch)
- Für 2–4 Spieler
- Gleichmäßige Verteilung von Spielern und Decks
- Übersichtlicher Turnierplan mit CSV-Export

### 🔸 Tournament Tool Advanced
- Auswahl zwischen mehreren Turniermodi (Spieleranzahl + Deckanzahl)
- Dynamische Rückrunde (optional)
- Punktetracking für Spieler und Decks
- Automatische Auswertung mit Diagrammen
- CSV-Export

## Nutzung

### Lokal

```bash
pip install -r requirements.txt
streamlit run main_app.py
```

### Online (empfohlen)

1. GitHub-Repository klonen oder erstellen
2. Dateien hochladen
3. Auf [streamlit.io/cloud](https://streamlit.io/cloud) deployen
4. `main_app.py` als Startdatei setzen
